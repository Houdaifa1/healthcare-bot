1. 🔐 Authentification - Obtenir un Token

Description: Génère un token d'authentification chiffré pour accéder aux autres endpoints.
POST https://stage.clinops.app/new-backend/external_module/getAccesAutorisation

📤 Request Body

{
  "username": "<username>",
  "password": "<password>"
}

📥 Response (Succès - 200)

{
  "success": true,
  "token": "encrypted_token_string"
}

❌ Erreurs Possibles

400: JSON invalide ou champs manquants
401: Identifiants invalides
502: Erreur de configuration Keycloak
503: Service d'authentification indisponible
504: Timeout du service d'authentification

📋 Paramètres

Paramètre Type Requis Description
username string REQUIS Nom d'utilisateur
password string REQUIS Mot de passe
⚠️ Note: Le token retourné est chiffré. Utilisez-le directement dans le header Authorization: Bearer <token> pour les autres endpoints. Limite: 5 requêtes par minute.

4. 🔍 Recherche de Patients

Description: Recherche des patients avec filtres optionnels. Les résultats sont triés avec les correspondances exactes en premier lors du filtrage par CIN/passeport. Optionnellement, peut filtrer uniquement les patients avec numéro de téléphone vérifié.
GET https://stage.clinops.app/new-backend/external_module/searchPatientsInfos

🔑 Headers Requis

Content-Type: application/json
Authorization: Bearer <encrypted_token>

📤 Request Body

{
  "cin_passeport": "CIN1128",
  "date_derniere_consultation": "2025-08-27",
  "motif": "Consultation",
  "numeroTelephone": "+212666666666",
  "OnlyVerifiedNumbers": false
}

📥 Response (Succès - 200)

{
  "success": true,
  "data": [
    {
      "patient_id": 1128,
      "patient": "Hind BEN",
      "cin": "CIN1128",
      "sexe": "M",
      "age_years": 55,
      "ville": "Tanger",
      "pays": "Maroc",
      "date_derniere_admission": "2025-04-30T12:55:10.019303+00:00",
      "prestation": "Scanner cérébral",
      "medecin_traitant": "DR Miloud BAKOUCHE",
      "solde_impaye": "0.00",
      "numeroTelephonePrincipale": "+212666666666",
      "numeroTelephoneSecondaire": null
    }
  ]
}

❌ Erreurs Possibles

400: Au moins un filtre requis (cin_passeport, motif, ou numeroTelephone)
400: Format invalide (CIN, date, ou téléphone)
401: Token d'authentification invalide ou manquant
500: Erreur serveur interne

📋 Paramètres

Paramètre Type Requis Format
cin_passeport string CONDITIONNEL* Alphanumérique, max 18 caractères
date_derniere_consultation string OPTIONNEL YYYY-MM-DD
motif string CONDITIONNEL* Raison d'admission
numeroTelephone string CONDITIONNEL* +212666666666
OnlyVerifiedNumbers boolean OPTIONNEL true/false (défaut: false). Si true, retourne uniquement les patients avec phone_number_verified = TRUE
* Au moins un des paramètres cin_passeport, motif, ou numeroTelephone est requis.

5. 📋 Historique des Prestations d'un Patient

Description: Récupère l'historique complet des prestations d'un patient par son numéro CIN/passeport ou numéro de téléphone.
GET https://stage.clinops.app/new-backend/external_module/getPatientHistory

🔑 Headers Requis

Content-Type: application/json
Authorization: Bearer <encrypted_token>

📤 Request Body

{
  "cin_passeport": "CIN1128"
}

OU

{
  "numeroTelephone": "+212666666666"
}

📥 Response (Succès - 200)

{
  "success": true,
  "data": {
    "patient": "Hind BEN",
    "solde_impaye": 1500.50,
    "admissions": [
      {
        "date_admission": "2025-04-30T12:55:10",
        "motif_admission": "Consultation",
        "medecin_traitant": "DR Miloud BAKOUCHE",
        "actes_realises": ["Scanner cérébral", "Consultation"],
        "produits_pharmaceutiques": ["Paracétamol 500mg"],
        "avis_medicaux": []
      }
    ]
  }
}

❌ Erreurs Possibles

400: Au moins un paramètre requis (cin_passeport ou numeroTelephone)
400: Format invalide
400: Aucun patient trouvé avec cet identifiant
401: Token d'authentification invalide
500: Erreur serveur interne

📋 Paramètres

Paramètre Type Requis Format
cin_passeport string CONDITIONNEL* Alphanumérique, max 18 caractères
numeroTelephone string CONDITIONNEL* +212666666666
* Au moins un des deux paramètres est requis.

6. ➕ Créer un Nouveau Patient

Description: Crée un nouveau patient dans le système avec toutes les informations nécessaires.
POST https://stage.clinops.app/new-backend/external_module/createNewPatient

🔑 Headers Requis

Content-Type: application/json
Authorization: Bearer <encrypted_token>

📤 Request Body

{
  "nom": "BEN",
  "prenom": "Hind",
  "sexe": "M",
  "type_identite": "CIN",
  "numero_identite": "CIN1128",
  "telephone_prefix": "+212",
  "telephone": "0612345678",
  "date_naissance": "1970-03-17",
  "ville_naissance": "Tanger",
  "ville": "Tanger",
  "pays": "Maroc",
  "adresse_principale": "123 Rue Example"
}

📥 Response (Succès - 200)

{
  "success": true,
  "message": "Patient créé avec succès",
  "patient_id": 1234
}

❌ Erreurs Possibles

400: Champs obligatoires manquants
400: Format invalide (nom, prénom, date, etc.)
400: Patient déjà existant avec ce numéro d'identité
401: Token d'authentification invalide
500: Erreur serveur interne

📋 Paramètres

Paramètre Type Requis Format/Valeurs
nom string REQUIS Max 50 caractères, lettres uniquement
prenom string REQUIS Max 50 caractères, lettres uniquement
sexe string REQUIS M ou F
type_identite string REQUIS CIN, PASSEPORT, CARTE SEJOUR, PAS D'IDENTITE
numero_identite string CONDITIONNEL* Requis sauf si type_identite = "PAS D'IDENTITE"
telephone_prefix string REQUIS Ex: +212
telephone string REQUIS Chiffres uniquement, max 16
date_naissance string REQUIS YYYY-MM-DD
ville_naissance string REQUIS Max 100 caractères
ville string REQUIS Max 100 caractères
pays string REQUIS Max 100 caractères (défaut: "Maroc")
adresse_principale string REQUIS Max 300 caractères

7. 📅 Disponibilités d'un Médecin

Description: Récupère les créneaux horaires disponibles pour un médecin à une date précise.
GET https://stage.clinops.app/new-backend/external_module/getDoctorsAvailability

🔑 Headers Requis

Content-Type: application/json
Authorization: Bearer <encrypted_token>

📤 Request Body

{
  "nom_medecin": "DR Miloud BAKOUCHE",
  "date_prevue": "2025-12-15"
}

📥 Response (Succès - 200)

{
  "success": true,
  "data": [
    {
      "heure_debut": "08:00:00",
      "heure_fin": "10:00:00"
    },
    {
      "heure_debut": "14:00:00",
      "heure_fin": "18:00:00"
    }
  ]
}

❌ Erreurs Possibles

400: Le nom du médecin est requis
400: La date prévue est requise
400: Format de date invalide (doit être YYYY-MM-DD)
400: Aucun médecin trouvé avec ce nom
401: Token d'authentification invalide
500: Erreur serveur interne

📋 Paramètres

Paramètre Type Requis Format
nom_medecin string REQUIS Nom complet (ex: "DR Miloud BAKOUCHE"), max 100 caractères
date_prevue string REQUIS YYYY-MM-DD

8. 📅 Médecins Disponibles par Date et Heure

Description: Récupère tous les médecins disponibles pour une spécialité donnée à une date et heure précises.
GET https://stage.clinops.app/new-backend/external_module/getAvailableDoctorsByDate

🔑 Headers Requis

Content-Type: application/json
Authorization: Bearer <encrypted_token>

📤 Request Body

{
  "specialite_id": 1,
  "date": "2025-12-15",
  "heure": "10:00"
}

📥 Response (Succès - 200)

{
  "success": true,
  "data": [
    {
      "doctorId": 10,
      "doctorLabel": "DR Miloud BAKOUCHE"
    },
    {
      "doctorId": 15,
      "doctorLabel": "DR Ahmed BENALI"
    }
  ]
}

❌ Erreurs Possibles

400: specialite_id, date et heure sont requis
400: specialite_id doit être un entier
400: Format de date invalide. Utilisez YYYY-MM-DD
400: Format d'heure invalide. Utilisez HH:MM
401: Token d'authentification invalide
500: Erreur serveur interne

📋 Paramètres

Paramètre Type Requis Format
specialite_id integer REQUIS ID de la spécialité
date string REQUIS YYYY-MM-DD
heure string REQUIS HH:MM
ℹ️ Note: Cette API retourne uniquement les médecins qui sont disponibles à la date et heure spécifiées (non bloqués par des indisponibilités ou des rendez-vous existants).

9. 📝 Créer un Rendez-vous

Description: Crée un nouveau rendez-vous. Supporte 4 scénarios: patient existant par ID, patient existant par CIN, nouveau patient sans CIN, nouveau patient avec CIN.
POST https://stage.clinops.app/new-backend/external_module/createNewRDV

🔑 Headers Requis

Content-Type: application/json
Authorization: Bearer <encrypted_token>

📤 Request Body - Scénario 1: Patient Existant par ID

{
  "patientId": 1128,
  "datePrevue": "2025-12-15T10:00:00",
  "motif": "Consultation",
  "medecinTraitant": "DR Miloud BAKOUCHE"
}

📤 Request Body - Scénario 2: Patient Existant par CIN

{
  "numero_identite": "CIN1128",
  "datePrevue": "2025-12-15T10:00:00",
  "motif": "Consultation",
  "medecinTraitant": "DR Miloud BAKOUCHE"
}

📤 Request Body - Scénario 3: Nouveau Patient sans CIN

{
  "nom": "EL",
  "prenom": "Souad",
  "sexe": "M",
  "type_identite": "PAS D'IDENTITE",
  "telephone_prefix": "+212",
  "telephone": "0612345678",
  "datePrevue": "2025-12-15T10:00:00",
  "motif": "Consultation",
  "medecinTraitant": "DR Miloud BAKOUCHE"
}

📤 Request Body - Scénario 4: Nouveau Patient avec CIN

{
  "nom": "EL",
  "prenom": "Souad",
  "sexe": "M",
  "type_identite": "CIN",
  "numero_identite": "CIN1128",
  "telephone_prefix": "+212",
  "telephone": "0612345678",
  "date_naissance": "1970-03-17",
  "pays": "Maroc",
  "datePrevue": "2025-12-15T10:00:00",
  "motif": "Consultation",
  "medecinTraitant": "DR Miloud BAKOUCHE"
}

📥 Response (Succès - 200)

{
  "success": true,
  "message": "Rendez-vous créé avec succès"
}

❌ Erreurs Possibles

400: Champs obligatoires manquants
400: Format de date invalide (doit être ISO: 2025-12-15T10:00:00)
400: Le motif n'existe pas ou n'est pas actif
400: Aucun médecin trouvé avec ce nom
400: Impossible de trouver une chambre/service
401: Token d'authentification invalide
500: Erreur serveur interne

📋 Paramètres

Paramètre Type Requis Description
patientId integer CONDITIONNEL ID du patient existant (Scénario 1)
numero_identite string CONDITIONNEL CIN/passeport (Scénario 2 ou 4)
nom string CONDITIONNEL Requis si nouveau patient (Scénario 3 ou 4)
prenom string CONDITIONNEL Requis si nouveau patient (Scénario 3 ou 4)
sexe string CONDITIONNEL M ou F (Scénario 4)
type_identite string CONDITIONNEL Requis si nouveau patient (Scénario 4)
telephone_prefix string CONDITIONNEL Requis si nouveau patient (Scénario 3 ou 4)
telephone string CONDITIONNEL Requis si nouveau patient (Scénario 3 ou 4)
date_naissance string CONDITIONNEL YYYY-MM-DD (Scénario 4)
pays string CONDITIONNEL Scénario 4
datePrevue string REQUIS Format ISO: 2025-12-15T10:00:00
motif string REQUIS Diagnostic (doit exister en base, insensible à la casse)
medecinTraitant string REQUIS Nom complet du médecin (doit exister en base)
⚠️ Validation: Le système valide que le motif et le medecinTraitant existent dans la base de données avant de créer le rendez-vous.
